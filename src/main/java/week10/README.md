## Coding assignments
Located in `assigment_problems/`:
1. `CancelledOrdersCleanup.java` — remove every matching value from a singly linked list without using `java.util.LinkedList`. Time O(n), removal space O(1).
2. `PriorityTokenInsertion.java` — add at front/end and insert at a 0-based index in a singly linked list. addFirst O(1), addLast O(n), insertAt O(n).
3. `ReverseQueue.java` — reverse a singly linked list in place without creating nodes. Time O(n), extra space O(1).
4. `TrainCoachesBothWays.java` — doubly linked train coaches with forward/backward printing and removal by name. Search O(n), unlink O(1), addLast O(1).
5. `RoundRobinGameTurns.java` — circular singly linked list with tail reference. addLast O(1), printTurns(t) O(t).

Each Java solution includes a `main` method. The new assignment solutions use sample values from the PDFs; `ReverseQueue` reads a whitespace-separated list from standard input.
